# Void Skins (Forge 1.21.1, client-side)

Меню выбора скина для мечей и кирок. Клавиша **K** (меняется в настройках управления).
Кнопка листает скины: Default / Void / Ice / Blood / Toxic / Ember. Выбор хранится в `config/voidskins.json`.
Мод клиентский, на сервер ставить не нужно. Нужен Forge 52.x для Minecraft 1.21.1.

## Сборка jar без установки Java
1. Создайте репозиторий на github.com и загрузите все файлы проекта вместе с папкой `.github`.
2. Вкладка **Actions** -> дождитесь зелёной галочки у `build`.
3. В Artifacts скачайте `voidskins-forge-jar`, внутри `voidskins-1.0.0.jar`.
4. Положите jar в `.minecraft/mods`.

# Void Skins (Forge 1.21.4, client-side)

Клавиша **K** открывает меню. Кнопки листают скины (Default / Void / Ice / Blood / Toxic / Ember),
кнопка **Apply (reload)** создаёт ресурспак VoidSkinsAuto в папке resourcepacks, включает его и перезагружает ресурсы.
Выбор хранится в `config/voidskins.json`. Мод клиентский, на сервер ставить не нужно.
